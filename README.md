## 🚀 Projetos em destaque

### 🏪 Sistema de Gestão de Pequenos Negócios
Sistema para ajudar pequenos empreendedores a controlar clientes, produtos e vendas.
- Modelagem de domínio com entidades relacionais e CRUD completo de clientes
- Validações de negócio (CPF e telefone únicos) e tratamento global de exceções
- Testes unitários e de integração com **JUnit, Mockito e H2**
- Documentação da API com **Swagger/OpenAPI**
- **Stack:** Java 21, Spring Boot, Spring Data JPA, PostgreSQL, MapStruct
- 🔗 [Ver repositório](https://github.com/alessandromelo22/product-management)

### 📱 API de Gerenciamento de Dispositivos Móveis (MDM)
API RESTful para cadastro e controle de usuários, departamentos e dispositivos móveis corporativos.
- Arquitetura em camadas: Controller, Service, Repository, DTO, Exception e Mapper
- Tratamento global de exceções com `@RestControllerAdvice` e validação com Hibernate Validator
- **Stack:** Java 21, Spring Boot 3.4.4, Spring Web, Spring Data JPA/Hibernate, PostgreSQL
- 🔗 [Ver repositório](https://github.com/AlessandroMelo22/mobile-device-management)
